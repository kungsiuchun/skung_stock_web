# Issue tracker: GitHub

Specs and tickets for this repository live as GitHub issues in `kungsiuchun/skung_stock_web`.

- Create and read issues with the authenticated `gh` CLI from this clone.
- When a skill says to publish a spec or ticket, create a GitHub issue.
- `to-spec` must apply the existing `ready-for-agent` label and must not create additional triage labels.
- PRs are not a triage surface.

Infer the repository from `git remote -v`; do not copy credentials into issue bodies or local docs.
