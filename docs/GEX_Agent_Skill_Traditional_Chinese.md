# 期權 GEX 量化決策助手 (Options GEX Decision Agent) - 技能設定

此技能旨在透過分析做市商（Market Makers）的 GEX（Gamma 敞口）與三大關鍵點位，判斷當前市場是處於「震盪」還是「趨勢」模式，並為用戶提供量化的期權交易決策指導。

---

## 📥 步驟一：獲取輸入變數 (Inputs)
AI Agent 執行決策前，需獲取以下數據：
- **GEX_Value**: 當前 GEX 數值（正值或負值）。
- **Current_Price**: 市場當前價格。
- **ZG (Zero Gamma)**: 市場模式的開關與分界線。
- **SG_High**: 天花板壓力位。
- **SG_Low**: 懸崖邊緣與加速點位。

---

## 🧠 步驟二：核心決策邏輯 (Decision Tree)

### 🟢 分支 A：當 GEX 為正值 (Positive GEX)
- **市場環境判斷**：
    - **模式**：「橡皮筋模式」。
    - **特徵**：價格波動減弱，走勢黏糊。做市商進行「高拋低吸」，成為市場「穩定器」。
- **用戶心態**：設定為「震盪」模式，捕捉小波段。
- **行動策略**：
    - **接近 SG_High**：上漲動能衰竭。考慮輕倉做空或賣出看漲期權 (Sell Call)。
    - **跌向 ZG 或 SG_Low**：下跌動能減弱。考慮輕倉做多或賣出看跌期權 (Sell Put)。
- **🚫 絕對禁忌**：追漲殺跌，期待單邊大行情。

### 🔴 分支 B：當 GEX 為負值 (Negative GEX)
- **市場環境判斷**：
    - **模式**：「滑滑梯模式」。
    - **特徵**：波動性放大，做市商「追漲殺跌」，成為市場「加速器」。
- **用戶心態**：設定為「趨勢」模式，順勢而為。
- **行動策略**：
    - **價格在 ZG 之上**：助漲模式，可能出現逼空。順勢做多，不可因「漲太多」而開空。
    - **價格跌破 SG_Low**：極度危險信號！加速下跌。立即止損多頭，激進者可反手做空。
- **🚫 絕對禁忌**：逆勢抄底或摸頂。
